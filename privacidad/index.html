Lo corto

Esta web no tiene formularios, cuentas, cookies, publicidad ni analítica. No recogemos tus datos.

Responsable

Alojamiento

La web está alojada en GitHub Pages, un servicio de GitHub, Inc. Como cualquier servidor web, GitHub registra datos técnicos de cada visita (por ejemplo, la dirección IP) para servir la página y por seguridad. GitHub puede tratar estos datos fuera del Espacio Económico Europeo. Puedes consultar cómo lo hace en su declaración de privacidad.

Calculadora

La calculadora funciona entera en tu navegador. Las cifras que introduces no se envían a ningún sitio. Solo se guarda en tu navegador (almacenamiento local) el idioma que elijas, para recordarlo la próxima vez. Puedes borrarlo desde los ajustes de tu navegador.

Tipografías y vídeos

Las tipografías están alojadas en esta misma web, sin llamadas a Google Fonts. Los vídeos no están incrustados: al pulsar un enlace vas a YouTube, que aplica su propia política de privacidad y de cookies.
